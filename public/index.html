🩺 Clinical Pathology & Biomarkers

Optical Coherence Tomography (OCT) allows micrometer-resolution visualization of distinct anatomical retinal layers and their pathological biomarkers.

CNV 🔴 Urgent

Choroidal Neovascularization: Pathological new blood vessel proliferation penetrating the Bruch's membrane into the sub-RPE space.

Hallmarks: Subretinal fluid (SRF) accumulation, hyperreflective fibrovascular membrane, RPE elevation.
DME 🟠 Priority

Diabetic Macular Edema: Retinal microvascular breakdown causing plasma extravasation and neurosensory thickening.

Hallmarks: Hyporeflective intraretinal cystoid fluid bubbles, diffuse retinal thickening, loss of foveal depression.
DRUSEN 🟣 Monitor

Drusen Deposits: Extracellular lipid and proteinaceous deposits between the RPE basement membrane and Bruch's layer.

Hallmarks: Undulating, dome-shaped elevations of the hyperreflective RPE layer with preserved inner retina.
NORMAL 🟢 Healthy

Normal Retina: Healthy neurosensory retinal architecture with zero fluid accumulation or structural compromise.

Hallmarks: Intact symmetric foveal pit, distinct stratification (RNFL, GCL, IPL, INL, OPL, ONL, ELM, EZ, RPE).

🚀 Launch the Full Interactive Streamlit Dashboard

The interactive diagnostic application runs natively on Docker, Streamlit Community Cloud, or your local Python environment.

🐳 Option 1: Docker (1-Command)

Run the containerized app with zero Python setup. All models and assets are pre-configured:

# Build and launch with Docker Compose
docker compose up -d

# Open browser at:
http://localhost:8502

🐍 Option 2: Local Python

Run natively in your local Python 3.10+ virtual environment:

# Install dependencies
pip install -r requirements.txt

# Start the Streamlit application
streamlit run app.py

☁️ Option 3: Streamlit Community Cloud

Free, 1-click cloud deployment with full PyTorch and GPU support:

1. Go to share.streamlit.io
2. Connect your GitHub repo: harshar007/Retinal-Disease-Detection-Using-Deep-Learning-on-OCT-Images
3. Set Main file path: app.py
4. Click Deploy!
